# Live deployment files for site one (admin-division2)

Generated by `sites/export-live.php` (SITE_KEY=one) from the local `/site-one/` page, re-aimed at https://admin-division2.immigration.go.th/wp
(logo and portrait in its Media Library, structure link, menu "main-menu").

- `site-one.template.json`: the page as an Elementor TEMPLATE. This is the file to use (see "How it was deployed").
- `site-one.page.kit.zip`: the same page as a one-page kit. NOTE: in Elementor 4.3.5 importing a content kit creates the page but leaves it EMPTY
  (reproduced locally with Elementor's own export too), so do not rely on it.

## How it was deployed (works)
1. Import `foundry/kit/design-system.kit.zip` (and `design-system-1.1-additions.kit.zip`) so the Global Colors / Fonts exist.
2. Create an empty page "Site one" (slug `site-one`, template Elementor Canvas), open it in the Elementor editor.
3. Templates > Saved Templates > Import `site-one.template.json`, then in the editor: Add Template (folder icon) > My Templates > Insert "Site one". Save as draft.
   (Automated from a logged-in session: `elementorCommon.ajax.addRequest('import_template', ...)`, `elementor.templates.requestTemplateContent`, then
   `$e.run('document/elements/create', ...)` for each top-level section and `$e.run('document/save/draft')`.)
4. Delete the helper template from the library, review, publish.
