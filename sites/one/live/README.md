# Live deployment files for site one (admin-division2)

Generated by `sites/export-live.php` (SITE_KEY=one) from the local `/site-one/` page, re-aimed at https://admin-division2.immigration.go.th/wp
(logo and portrait in its Media Library, structure link, menu "main-menu").

- `site-one.page.kit.zip`: one-page Elementor kit. Import with Elementor's importer (Tools > Import/Export Kit). Creates the page "Site one" (Elementor Canvas).
- `site-one.template.json`: the same page as an Elementor template (Templates > Saved Templates > Import), the manual fallback.

Import `foundry/kit/design-system.kit.zip` (and the 1.1 additions kit) first so the Global Colors and Fonts exist.
