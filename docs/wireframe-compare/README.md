# Wireframe comparison: the two sites' home page designs

The designer's two wireframes, side by side, cut into matching sections.

| File | Site | Name on the page |
|---|---|---|
| `bk-tm2.html` | **division2.immigration.go.th** (site "two") | กองบังคับการตรวจคนเข้าเมือง 2 |
| `admin-tm2.html` | **admin-division2.immigration.go.th** (site "one") | ฝ่ายอำนวยการ บก.ตม.2 |

## How to look at it
Double-click **`compare.html`** (works offline, no server needed). `wireframe-overlap.png` is the same picture as a flat image.
Keep the `assets/` folder next to the HTML files (it holds the shared stylesheet `imm-system.css`).

## What the colours mean
- **Green, shared (6):** contact strip, masthead and menu, online services, commanders, videos, footer. These are built once as foundry components and used by both sites.
- **Amber, same slot but different content (2):** hero, news.
- **Blue, only site two (1):** gift-refusal policy.
- **Orange, only site one (3):** document downloads, contact form, affiliated units.
